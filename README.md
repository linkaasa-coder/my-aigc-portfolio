# AIGC 个人作品集网站

这是一个纯静态、响应式的个人作品集网页，适合展示 AIGC 视频创作、视频剪辑、文案与视觉设计能力。无需安装依赖。

## 文件
- `index.html`：完整网站。双击即可在浏览器本地预览。

## 发布前建议修改
1. 搜索并替换 `your-email@example.com` 为你的邮箱。
2. 将作品卡片的 `href="#contact"` 替换为真实视频链接（如公开的视频页面或网盘分享链接）。
3. 把示意封面替换为真实作品截图。当前封面是网页内置 CSS 设计的示意图，不代表真实成片。
4. 将作品标题、创作说明和技能调整为真实经历；不要保留不符合实际情况的工具或项目描述。

## 免费发布到 GitHub Pages
1. 登录 GitHub 并新建一个公开仓库，例如 `my-aigc-portfolio`。
2. 上传 `index.html` 到仓库根目录并提交。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
5. 等待部署完成，GitHub Pages 会显示公开网址，格式通常类似 `https://你的用户名.github.io/my-aigc-portfolio/`。
6. 把这个网址发给招聘方即可。首次部署可能需要几分钟。

## 隐私提醒
发布到公开网站的作品与联系方式任何人都可能看到。发布前确认你有权公开展示相关素材；不要上传含有隐私或客户机密的内容。
